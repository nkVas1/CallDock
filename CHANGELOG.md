# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Раздел версии становится текстом выпуска на GitHub и блоком «Что нового» в настройках программы, когда обновление скачано.

## [1.2.0] — 2026-10-07

### Добавлено
- CallDock замечает звонки. Когда приложение включает микрофон — Zoom, Телемост, Telegram, Teams, встреча в браузере —
  в углу экрана появляется подсказка «записать звонок?». Она не отнимает фокус у разговора. Можно выбрать
  «Записывать сразу» или выключить подсказки («Настройки → Запись»). Запись, начатая ради звонка, по его окончании
  предлагает завершиться и через минуту завершается сама, если её не продлить.

### Изменено
- Звук не теряется, когда медленный диск на несколько секунд занят, например записью экрана: очередь звука теперь
  на минуту, а не на пять секунд, а заголовок WAV обновляется раз в секунду, а не десять раз.
- Если звук всё же пропал, у дорожки написано, сколько миллисекунд.

## [1.1.0] — 2026-10-07

### Добавлено
- Сведение дорожек. После записи экрана его видео получает звук всех дорожек — готовый ролик, картинка не копируется;
  после звонка без экрана — общий звук в M4A. «Слушать» и щелчок по фразе в архиве играют сведение. На вкладке
  «Дорожки» его можно послушать, посмотреть, сохранить или свести заново — выбрать голоса и картинку. Записи
  нескольких трансляций из Chrome сами не сводятся, только по выбору.
- Источники подключаются и отключаются во время записи: переключатель на карточке или «Добавить источник». Каждая
  дорожка встаёт на шкалу времени туда, где началась; источник, включённый снова, остаётся тем же говорящим.
- Запись, начатая из Chrome, может сразу включить источники CallDock — микрофон, системный звук, экран: галочка
  «Вместе с источниками CallDock» в расширении. К уже идущей записи их можно добавить в самом CallDock.
- Настройка «Сводить дорожки после записи».

### Изменено
- Экран пишется с постоянной частотой кадров: на загруженном компьютере видео больше не «убегает» от звука.
- Начало дорожек определяется точнее: вкладка Chrome сообщает, когда реально началась её запись, а видео экрана
  сверяется по моменту остановки.
- Включённые и выключенные источники запоминаются между запусками.
- «Все голоса одной дорожкой» сводятся так же, как сведение записи: без приглушения голосов, с ограничителем.
- Понятные подписи формата («48 кГц · стерео · FLAC 24 бит без потерь») и время каждой дорожки в списке.
- Переключатели источников называются по подписи источника — для экранного диктора.

### Исправлено
- Окно видео в Windows 10 больше не включает эффект Mica, который там не работает.

## [1.0.1] — 2026-10-03

### Исправлено
- Проверка обновлений больше не «висит» за неработающим прокси или VPN: если GitHub не ответил за минуту, CallDock
  скажет об этом и проверит снова при следующем запуске.
- Загрузка модели распознавания продолжается с места обрыва. Если больше минуты не приходит ни байта, загрузка
  останавливается с понятным сообщением вместо бесконечного ожидания; повторное «Скачать» продолжит её.
- Окно расширения просит перезагрузить его в Chrome только когда с обновлением пришла новая версия расширения.
- В настройках Chrome — подсказки про режим «Без видео» и перезагрузку расширения после обновления.

### Добавлено
- Скачанное обновление показывает, что в нём нового: «Настройки → Обновления»; о самой загрузке сообщает уведомление.

## [1.0.0] — 2026-10-03

Первый публичный выпуск.

### Запись
- Микрофон и системный звук пишутся отдельными дорожками в исходном качестве: во время записи — WAV, после — FLAC 24 бит без потерь (примерно втрое меньше).
- Звук отдельного приложения (Windows 11), экран или окно в H.264, поток по прямой ссылке (HLS, DASH).
- До четырёх вкладок Chrome одновременно через расширение CallDock: каждая — своей дорожкой со звуком и видео (720p или 1080p) или только звуком. Другие вкладки, программы и игры в запись не попадают.
- Живые индикаторы уровня для каждого источника и проверка звука до начала записи.
- Метки по ходу разговора; горячие клавиши Ctrl+Alt+R (начать/завершить) и Ctrl+Alt+M (метка) работают из любой программы.
- Работа из трея: окно можно закрыть, запись продолжится.
- Запись сохраняется по ходу и восстанавливается после сбоя или выключения компьютера.

### Расшифровка
- Распознавание речи Whisper прямо на компьютере: звук никуда не отправляется. Три модели на выбор — скачиваются один раз и проверяются по SHA-256.
- Говорящие подписаны по названиям источников: «Я», «Собеседники», «Зал 1».
- Отсеиваются типичные выдумки Whisper на тишине («Субтитры сделал…», «Продолжение следует…»).

### Архив
- Поиск по названию, проекту, тегам и словам из разговора.
- Плеер: щелчок по фразе включает её звук, текущая фраза подсвечивается и не уходит из виду.
- Экспорт текста в TXT, Markdown, SRT, VTT и JSON; дорожек и общего микса — в WAV, FLAC, MP3 и M4A.
- Записи вкладок получают индекс перемотки и открываются в любом плеере; если компьютер не успевал и звук вкладки оказался короче видео, программа об этом скажет.

### Программа
- Установщик с автообновлением из GitHub Releases и переносимая ZIP-версия.
- Тёмная и светлая темы; режим совместимой отрисовки для старых видеодрайверов.
- Настройки и код подключения расширения переживают переустановку.
