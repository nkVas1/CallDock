# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Раздел версии становится текстом релиза на GitHub и окном «Что нового» при обновлении.

## [1.0.0] — 2026-10-03

Первый публичный выпуск.

### Запись
- Микрофон и системный звук пишутся отдельными дорожками в исходном качестве: во время записи — WAV, после — FLAC 24 бит без потерь (примерно втрое меньше).
- Звук отдельного приложения (Windows 11), экран или окно в H.264, поток по прямой ссылке (HLS, DASH).
- До четырёх вкладок Chrome одновременно через расширение CallDock: каждая — своей дорожкой со звуком и видео (720p или 1080p) или только звуком. Другие вкладки, программы и игры в запись не попадают.
- Живые индикаторы уровня для каждого источника и проверка звука до начала записи.
- Метки по ходу разговора; горячие клавиши Ctrl+Alt+R (начать/завершить) и Ctrl+Alt+M (метка) работают из любой программы.
- Работа из трея: окно можно закрыть, запись продолжится.
- Запись сохраняется по ходу и восстанавливается после сбоя или выключения компьютера.

### Расшифровка
- Распознавание речи Whisper прямо на компьютере: звук никуда не отправляется. Три модели на выбор — скачиваются один раз и проверяются по SHA-256.
- Говорящие подписаны по названиям источников: «Я», «Собеседники», «Зал 1».
- Отсеиваются типичные выдумки Whisper на тишине («Субтитры сделал…», «Продолжение следует…»).

### Архив
- Поиск по названию, проекту, тегам и словам из разговора.
- Плеер: щелчок по фразе включает её звук, текущая фраза подсвечивается и не уходит из виду.
- Экспорт текста в TXT, Markdown, SRT, VTT и JSON; дорожек и общего микса — в WAV, FLAC, MP3 и M4A.
- Записи вкладок получают индекс перемотки и открываются в любом плеере; если компьютер не успевал и звук вкладки оказался короче видео, программа об этом скажет.

### Программа
- Установщик с автообновлением из GitHub Releases и переносимая ZIP-версия.
- Тёмная и светлая темы; режим совместимой отрисовки для старых видеодрайверов.
- Настройки и код подключения расширения переживают переустановку.
